# UAV Search Animations

Hourly search plans of the best solution found by each algorithm, for every test instance.
Each GIF has one frame per search hour over the three search days. Click a GIF to open it at full size.

- **I-1 to I-8**: 2 UAVs, search on Days 1-3 after the incident.
- **I-9 and I-10** (delayed response): 3 UAVs, search starts the day after the incident (Days 2-4).
- **Run shown**: of the 30 independent runs, the run whose Day-3 cumulative POS is closest to the median (ties broken by fitness).

**Legend.** Black solid line: true drift trajectory so far. Orange dotted line: predicted trajectory so far. Purple dots: particles (they fade as their cumulative detection probability rises). Dashed rectangle: mission area. Coloured lines: UAV sweep paths, with a star at each start point.
